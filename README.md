# RPG Status Panel · 角色面板（示例）

一页游戏状态页风格的个人周指标可视化：六维／五维雷达、本周三项属性、等级与经验条、d20 骰子与支线任务，外加一张可读屏、可精确读数的维度清单表。

- 页面上的所有数字都是**虚构示例**，不对应任何真实个人的数据。
- 单个 HTML 文件，内联 CSS／JS／SVG，零依赖、零外部请求，断网也能打开。
- 快捷键：5／6 切五维／六维，T 切红／蓝主题，M 开关动态；也可用网址参数 `?theme=p5|p3&dims=5|6&motion=on|off`。
- 界面风格致敬 Persona 系列菜单美学；个人习作，非 ATLUS／SEGA 出品，与其无关，未使用任何游戏的标志、角色或素材。
